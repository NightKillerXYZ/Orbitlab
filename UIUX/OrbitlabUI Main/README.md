# OrbitLab prototype

A static, browser-based student mission control prototype. No build step or package installation is required.

## Run

Open `index.html` in a browser, or serve this folder with any static web server. For example, from this folder run `python -m http.server 8000` and visit `http://localhost:8000`.

## Included interactions

- Play/pause, reset, simulation speed, 2D/3D presentation, and simulation timeline.
- Scenario prompts in Mission Assistant with simulated orbital metrics.
- Chat, Understanding, Results, Graph, and Physics panels.
- CSV export containing sample Venus orbital telemetry.

The scenario outcomes and telemetry are educational prototype data, not a numerical physics engine.
